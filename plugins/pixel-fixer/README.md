# pixel-fixer

> 「もしもし。絵が一枚、まずいことになっています」
> 「状況は」
> 「ドット絵のはずが、一粒の中に色が十四色あります」
> 「そちらまで三十分ですね。十分で行きます」
> 「それまで、何をしておけば」
> 「何も触らないでください。特に、縮小は」

画像生成に「ドット絵で」と頼むと、ドット絵によく似た何かが届きます。一粒に見える四角は、実は数ピクセルの柔らかい塊です。塊の大きさも色も、絵ごとに少しずつ違います。縮めればにじみ、手で描き直せば別人になります。

`pixel-fixer` は、そういう絵を一粒ずつ描き直して、ゲームで動かせる本物のドット絵にするプラグインです。形は元絵から借ります。マス目と色は、ゲームの決まりに従わせます。片付けが終わったら、元絵と並べて見せます。

## 呼ぶ前に決めておくこと

**ドットの大きさは一つだけ。** 大きさの違うドットが隣り合うのは、ドット絵で一番目立つ揉め事です。全部の絵を、同じ大きさのドットで描きます。

**色は全員で同じパレットを使う。** 暗い順に並べた色の列を、十いくつか用意します。一人だけ違う色を着ている絵は、遠くからでも分かります。

**背景はマゼンタ (#FF00FF) で頼む。** 紫とピンクは背景と一緒に消えるので、絵には使わせません。頼んだ大きさとコマ数は控えておきます。後でマス目を割り出すときの手がかりになります。

## 片付けの手順

1. **マス目を割り出す。** 色の境目が繰り返す間隔から、生成器が実際に描いたマス目を見つけます。探すのは、頼んだ大きさの近くだけです。生成器は頼んだより細かく描くことはあっても、粗く描くことはありません。
2. **一粒ずつ描き直す。** 各マスの真ん中で一番多い色を、そのドットの色にします。平均は取りません。平均の色は、たいてい誰の色でもないからです。
3. **色をパレットに収める。** 色の近さは Lab で測ります。目に見える違いに近い物差しです。
4. **後始末をする。**
   - 少しだけ使われている色は、近くのよく使われている色にまとめます
   - 同じ色の仲間が一人もいないドットは、隣と同じ色にします
   - 平らな面に紛れ込んだ一、二粒は、面の色に戻します
   - 二重になった輪郭は、一本にします
   - 本体から離れて描かれた物は、なかったことにします
   - 一ドット幅の線は、そのまま残します
   - 目の光とハイライトは、一人で立っているのが仕事なので触りません
5. **色違いは、パレットの中で作る。** 衣装の色を変えるときは、パレットの列ごと入れ替えます。パレットの外から色を連れてくることはしません。

## 片付けの報告

報告のページで、すべてのコマを元絵の隣に並べます。

| 数字 | 意味 | 目安 |
|------|------|------|
| 重なり | 両方に共通する輪郭 ÷ どちらかにある輪郭 | 95% 以上。下回ったら、何かを取りこぼしています |
| 色の差 | 両方に色がある所の、Lab での平均の差 | 人物や小物で 10 前後、壁や扉で 6 前後 |

色の差は 0 になりません。元絵の方がぼやけているからです。0 になったら、どこかで帳尻を合わせています。

差の絵では、灰色が一致、橙から赤が色違い、赤は元絵にだけ、水色は描き直した絵にだけある所です。数字が良くても、最後は目で見ます。平らな面のざらつき、粗さのむら、パレットに無い色は、数字にはほとんど出ません。

| 種別 | 名前 | 説明 |
|------|------|------|
| Skill | `pixel-art-from-generated` | 片付けの手順。生成した絵をゲームで使う話になると Claude が読み込む |
| Script | `scripts/pixelart.py` | 手順の一つ一つ |
| Script | `scripts/readback.py` | 一枚の指示書で全部の絵をまとめて描き直し、報告のページを書く |

## 使い方

生成した絵を渡して「スプライトにして」と言うと、Claude が読み込みます。`/pixel-fixer:pixel-art-from-generated` で呼ぶこともできます。Python 3 と Pillow と numpy が要ります。

```
python3 scripts/readback.py spec.json <元絵のフォルダ> <出力フォルダ> report.html
```

指示書の書き方は `readback.py` の先頭にあります。

## よくある質問

**Q: 縮小して使えば早くないですか?**
A: 早いです。にじんだまま世に出すという意味では。

**Q: ドット絵専用の生成サービスなら、片付けは要りませんか?**
A: 決まった大きさと色で描いてくれます。コマ同士が同じ人物に見えるかまでは、約束してくれません。費用もかかるので、使う前に見積もりを持ち主に見せてください。

**Q: 片付けた跡は残りますか?**
A: 残りません。直されたドットは、隣と同じ色になって、何事もなかったように並んでいます。

連絡先は #FF00FF まで。
