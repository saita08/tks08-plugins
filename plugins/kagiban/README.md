# kagiban

> 「蔵には全部、錠をかけてあります」
> 「結構。鍵はどこに」
> 「錠の横に掛けてあります。失くすといけないので」

大店の蔵には、昔から鍵番がいました。錠をかけるのは誰にでもできます。鍵番の仕事は、その先です。何を蔵に入れ、何を帳場に出しておくか。鍵をどこに預け、合鍵を誰が持ち、錠をいつ掛け替えるか。番頭が夜中に蔵を開けたら、誰が気づくか。

データの暗号化も同じです。「暗号化してあります」と言うのは簡単で、たいていの場合は本当でもあります。クラウドがディスクごと錠をかけてくれているからです。ただ、その錠は蔵の壁ごと盗まれたときにしか効きません。帳面の写しが外に出たとき、番頭の合鍵が一本なくなったとき、荷を預けた運送屋が中身を控えていたとき、錠は何も言いません。

`kagiban` は、その鍵番の心得を書き付けたプラグインです。保存するデータの暗号化と鍵の扱いについて、OWASP、NIST、クラウドの KMS の作法、個人情報保護委員会のガイドラインと Q&A、IPA と CRYPTREC の鍵管理の設計指針に照らした判断の筋道を、Claude が読める形にしてあります。どの店にも通じるよう、特定の店の帳面のことは書いていません。

## 心得

**錠をかける前に、何を蔵に入れるかを決める。** 一番強い錠は、そもそも預からないことです。預かるものは、漏れたときの害と、帳場で毎日使うかどうかの二つで仕分けます。算盤を弾く数字や、客を探すための名前を蔵にしまうと、毎回蔵を開けに行くことになります。探す必要が残るものには blind index という札を付けますが、札は「同じものがある」ことまでは漏らします。帳面の写し、日誌、控えの束といった、蔵の外に置かれた写しも忘れずに数えます。

**錠と扉を対にする。** 錠前は認証付きの暗号(AES-256-GCM)で、標準の道具を使い、自分では作りません。錠にはどの鍵で開くかの札を付け、どの扉の錠かも刻んでおきます。隣の蔵に付け替えても開かないようにするためです。荷ごとに小さな鍵を作り、その鍵を親鍵で包む(エンベロープ暗号化)と、親鍵の掛け替えが軽くなり、客ごとの鍵を捨てれば、写しの残った控えまで読めなくなります。

**鍵は錠の横に掛けない。** 鍵は乱数で作り、KMS か秘密の置き場に預け、触れる人を絞ります。置き場が書き込み専用なら、合鍵を一本、別の場所に控えておきます。鍵を失くせば、蔵の中身は二度と出てきません。掛け替えの手順は、使う日が来る前に一度通しておきます。日本では、暗号化したデータと鍵を分けて管理していたかどうかで、漏えいしたときに報告が要るかどうかが変わります。鍵の置き場所は、法令の話でもあります。

**番頭も鍵を持っている。** アプリ側の暗号化は、店の外の盗人には効きますが、鍵を使って店を回している番頭には効きません。番頭の手を狭く、記録が残る形にすることはできます。番頭にも開けられない蔵(エンドツーエンド暗号化)も作れますが、そのとき店は、蔵の中身を見て行う仕事をすべて手放します。そして客には、本当にできることだけを言います。

**運送屋に預けた荷は、運送屋の決まりで扱われる。** 外部の API に送ったデータには、こちらの錠は届きません。何日控えるのか、不正の見張りのために別に控えるのか、学習に使うのか、控えさせない契約の条件は何か、消す手段はあるか、どこの国の倉庫か。一つずつ確かめ、出典と日付を残します。委託か第三者提供か、外国にある第三者に当たるかという日本の法令の枠も添えてあります。

数値は出典の版に基づいており、法令の部分は公表されたガイドラインの要約です。鍵番は錠前屋ではあっても、弁護士ではありません。契約やプライバシーポリシー、漏えいの報告を左右する判断は、専門家に回すよう書いてあります。

| 種別 | 名前 | 説明 |
|------|------|------|
| Skill | `data-encryption` | 鍵番の心得。何を暗号化するか、暗号文の作り方、鍵の扱い、運営者が見られる問題、外部 API の五つに分けて読む |

## 使い方

何もしなくていいです。データの暗号化、鍵の置き場所や掛け替え、外部 API に送るデータの扱いの話を始めると、Claude がこのスキルを読み込みます。スラッシュコマンドはありません。鍵番は呼ばれて来るものではなく、最初から蔵の前にいるものだからです。

## よくある質問

**Q: 全部暗号化すれば安心ではないですか?**
A: 全部に錠をかけた蔵は、帳場から算盤まで蔵の中にある店です。安心の前に、商売が止まります。

**Q: クラウドが暗号化してくれているなら、要らないのでは?**
A: 蔵の壁ごと盗む泥棒には、それで足ります。最近の泥棒は、写しを持って正面から帰ります。

**Q: 鍵は一本で足りますか?**
A: 足ります。失くすまでは。
